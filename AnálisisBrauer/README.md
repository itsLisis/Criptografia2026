Brauer configuration analysis for musical scores

Files:
- `parse_score.py`: Extract notes from MXL partitura into JSON with metadata (clef, key signature, alterations, durations).
- `brauer_analysis.py`: Compute M₀ (vertices), M₁ (polygons), valences, multiplicities μ, algebraic dimensions, and geometric trace.
- `plot_clean_trace.py`: Generate cleaned, de-overlapped trace images from the parsed JSONs (filters repeats, expands chords, split per part).
- `requirements.txt`: Python deps (numpy, matplotlib, networkx).
- `REPORTE_CRIPTOGRAFICO.md`: Cryptographic interpretation of results.

Notes:
- The script expects the JSON output generated by `parse_score.py` in `Partituras/`.
- Use `--crab` to also analyze the retrograded (reversed polygons) sequence.

uso de pruebas: python brauer_analysis.py Partituras/canon_per_argumentationem_contrario_motu.json --plot pruebas/mi_grafo.png --out pruebas/resultados.json --crab

Examples:

```bash
# 1. Extract notes from score
python parse_score.py

# 2. Analyze Brauer configuration
python brauer_analysis.py Partituras/super_thema_regium.json --out analysis_results.json --plot graph_STR.png

python brauer_analysis.py Partituras/crab_canon.json --out analysis_CRC.json --plot graph_CRC.png --crab

python brauer_analysis.py Partituras/canon_per_argumentationem_contrario_motu.json --out analysis_CPACM.json --plot graph_CPACM.png

python brauer_analysis.py Partituras/canon_perpetuus_per_giusti_intervalii.json --out analysis_CPGI.json --plot graph_CPGI.png

# 3. Generate cleaned trace images (reduce overlap)
python plot_clean_trace.py Partituras/super_thema_regium.json --out Resultados/graph_STR_clean.png --split-per-part

python plot_clean_trace.py Partituras/crab_canon.json --out Resultados/graph_CRC_clean.png --split-per-part

python plot_clean_trace.py Partituras/canon_per_argumentationem_contrario_motu.json --out Resultados/graph_CPACM_clean.png --split-per-part

python plot_clean_trace.py Partituras/canon_perpetuus_per_giusti_intervalii.json --out Resultados/graph_CPGI_clean.png --split-per-part
